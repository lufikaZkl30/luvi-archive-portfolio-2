# Luvi Asakura — Digital Archive Portfolio

A responsive React + Vite + Tailwind CSS portfolio inspired by layered archive folders, tactile paper, editorial typography, and a modern futuristic visual language.

## Run locally

Requirements: Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Customize before publishing

1. Open `src/App.jsx`.
2. Replace the placeholder GitHub links in the `projects` array with each real repository/demo URL.
3. Replace `hello@luvi.example` with your actual public email.
4. Check the experience dates and descriptions, and edit anything that doesn't match your real experience.
5. Update the GitHub profile URL in the footer if needed.

## Notes

- Folder tabs are interactive and switch the archive content.
- Project cards are responsive.
- The email address is intentionally a placeholder; don't publish it as-is.
- The YT Emotion Analyzer stack and project links should be verified before publication.
- Tailwind is configured and available; most visual styling currently lives in `src/index.css` for easier art-direction.
